
# Datasets

This project uses three publicly available financial fraud detection datasets.

---

# 🏦 D1 — Kaggle Credit Card Fraud Dataset

Source:

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Description:
- European cardholder transactions
- Highly imbalanced fraud dataset
- PCA-transformed features

---

# 🌐 D2 — Online Transaction Fraud Dataset

Source:

https://www.kaggle.com/datasets/kartik2112/fraud-detection

Description:
- Simulated online financial transactions
- Includes customer and merchant information
- Binary fraud classification

---

# 📱 D3 — PaySim Mobile Money Fraud Dataset

Source:

https://www.kaggle.com/datasets/ealaxi/paysim1

Description:
- Mobile money transaction simulation
- Large-scale financial transaction data
- Realistic fraud behavior simulation

---

# 📥 Download Instructions

Download datasets manually from Kaggle and place them inside:

```bash
datasets/
```

Expected structure:

```bash
datasets/
├── creditcard.csv
├── fraudTrain.csv
├── fraudTest.csv
└── PS_20174392719_1491204439457_log.csv
```
