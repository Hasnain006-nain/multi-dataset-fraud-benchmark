
# Figures

This folder contains all visualizations generated during the multi-dataset fraud detection benchmark experiments.

Included figures:

- Class distribution analysis
- Confusion matrices
- ROC curves
- Precision-Recall curves
- Recall comparison
- MCC comparison
- Training time analysis
- Inference latency analysis
- SHAP explainability plots
- Cross-dataset generalization analysis
- McNemar statistical significance testing

These figures were generated using Python, Matplotlib, Seaborn, SHAP, and Scikit-learn.
